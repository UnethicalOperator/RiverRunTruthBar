LEGACY FILES ONLY

The current Steam build of Liar's Bar uses Unity IL2CPP. The old ub0.dll and
SharpMonoInjector workflow in this folder target the obsolete Mono game build
and must not be used with the current game.

Use the repository-root RiverRunTruthBar.exe instead. Double-clicking it installs
or updates the current IL2CPP plugin and launches Liar's Bar through Steam.

In-game hotkeys:
F1  Show/hide the menu
F2  Close and reset the menu
L   Refresh game state
P   Reset overlay positions
